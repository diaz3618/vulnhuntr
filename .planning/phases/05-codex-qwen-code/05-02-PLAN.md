<!-- From 05-RESEARCH.md — key facts for implementation -->

Binary: "qwen" (NOT "qwen-code")
Headless flag: -p (confirmed, D-11 correct for Qwen Code)
JSON output flag: --output-format json (produces buffered JSON array at end)
_MIN_VERSION: (0, 1, 0) — JSON output available since Qwen Code v0.1
Install hint: "npm i -g @qwen-code/qwen-code"

Approval mode mapping:
  tool_mode "none"/"read-only" → --approval-mode plan  (read-only, analysis only)
  tool_mode "full"             → --yolo                 (auto-approve all tools)

Auth env vars to strip (D-09 corrected per research):
  - DASHSCOPE_API_KEY     (direct Qwen API key — discontinued OAuth, now direct API)
  - BAILIAN_CODING_PLAN_API_KEY  (Alibaba Cloud Coding Plan)
  - DO NOT strip OPENAI_API_KEY  (needed for bridge mode)
  - QWEN_API_KEY does NOT exist  (OAuth discontinued April 2026)

Bridge mode: CLIPolicy.overrides["qwen-code"]["base_url"] → inject as OPENAI_BASE_URL

JSON parse path:
  - json.loads(stdout) → list
  - find entry where type=="result" → primary data
  - result["result"] → response text
  - result["usage"] → token usage
  - result["is_error"] == True → CLIParseError
  - system entry["model"] → self.model

send_message() return: {"messages": messages_list} to keep dict[str, Any] contract.

Qwen Code CLI headless adapter for Vulnhuntr.

Verified against qwen 0.15.6. Key flags:
  qwen -p <prompt> --output-format json [--approval-mode plan | --yolo]

JSON array output (buffered at end, NOT streaming):

- `send_message()`:
  - del max_tokens, response_model
  - prepend system_prompt: `full_prompt = f"{self.system_prompt}\n\n{user_prompt}"` if `self.system_prompt` else `full_prompt = user_prompt`
  - tool_mode: `tool_mode = self._policy.tool_mode if self._policy else "none"`
  - cmd: `["qwen", "-p", full_prompt, "--output-format", "json"]`
  - if tool_mode == "full": `cmd.append("--yolo")` else: `cmd.extend(["--approval-mode", "plan"])`
  - `result = self._run_subprocess(cmd)`
  - if not result.stdout.strip(): raise CLIParseError
  - `messages = json.loads(result.stdout.strip())` with try/except JSONDecodeError → CLIParseError
  - if not isinstance(messages, list): raise CLIParseError(f"Qwen Code JSON output was not an array: {type(messages)}")
  - set model: `system_entry = next((m for m in messages if m.get("type") == "system"), {}); self.model = system_entry.get("model", "qwen-code")`
  - return `{"messages": messages}`
- `get_response(response)`:
  - `messages = response.get("messages") or []`
  - `result_entry = next((m for m in messages if m.get("type") == "result"), None)`
  - if result_entry is None: raise CLIParseError("Qwen Code JSON array contained no 'result' entry")
  - if result_entry.get("is_error"): raise CLIParseError(f"Qwen Code returned an error result: {result_entry.get('result', '')[:200]}")
  - `text = result_entry.get("result")` — if None: raise CLIParseError("Qwen Code 'result' entry missing 'result' field")
  - return str(text)

  - `messages = response.get("messages") or []`

  - if input_tokens > 0 or output_tokens > 0: return LLMUsage(input_tokens=..., output_tokens=..., model=self.model or "qwen-code")
  - fallback: find assistant entry; usage = msg.get("message", {}).get("usage", {}); return LLMUsage(...)
  - final fallback: return LLMUsage(0, 0, self.model or "qwen-code")

|----------|-------------|
| Vulnhuntr → qwen subprocess | Untrusted prompt text exits the Python process |
| qwen stdout → Vulnhuntr parser | JSON array from binary must be parsed defensively |
| bridge mode env | OPENAI_BASE_URL set from operator config; must not leak to wrong provider |

| T-05-06 | Information Disclosure | DASHSCOPE_API_KEY in subprocess env | mitigate | _STRIP_ENV_VARS contains both direct-Qwen auth keys; _build_env() removes them |
| T-05-07 | Tampering | JSON array parse from qwen stdout | mitigate | isinstance(messages, list) check; is_error check; missing field → CLIParseError |
| T-05-08 | Information Disclosure | OPENAI_BASE_URL injection (bridge mode) | accept | URL comes from operator config (CLIPolicy), not user input; operator is trusted |
| T-05-09 | Elevation of Privilege | --yolo mode executing arbitrary commands | accept | tool_mode "full" requires operator opt-in; default is plan (read-only) |

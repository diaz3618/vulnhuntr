<!-- CRITICAL: D-02 in CONTEXT.md is wrong for the current Codex CLI -->

CONTEXT.md D-02 maps tool_mode to --approval-mode suggest/auto-edit/full-auto.
These are from the deprecated TypeScript Codex CLI. The current Rust Codex CLI
(version 0.95+) uses a different flag pair:
  - Read-only:       --sandbox read-only --ask-for-approval never
  - Workspace write: --sandbox workspace-write --ask-for-approval never

D-02 intent is implemented correctly using these current flags. The old
--approval-mode flag does not exist in the Rust CLI.

CONTEXT.md D-11 says prompts via -p flag. Codex does NOT have -p. The prompt
is a positional argument: "codex exec [flags] '<prompt>'". Do NOT add -p.

Codex exec outputs JSONL (newline-delimited JSON, one object per line). It is
NOT a single JSON object. Use stdout.splitlines() + json.loads(line) per line.

send_message() return: wrap events in {"events": events_list} to maintain the
dict[str, Any] return contract of the base class abstract method.
</research_corrections>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI args → validate_args | User-supplied --root and --analyze paths cross here; untrusted filesystem inputs |
| checkpoint file → from_dict | JSON loaded from disk (potentially written by an older/different version) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Elevation of Privilege | validate_args() --analyze arg | mitigate | Use Path.resolve() + is_relative_to() to canonicalize before comparison; symlink escapes caught |
| T-01-02 | Tampering | checkpoint.py from_dict() | accept | Checkpoint file is written/read by the same local user; no cross-trust-boundary concern |
| T-01-03 | Information Disclosure | importlib.metadata.version() | accept | Package version is already public (PyPI); no secret exposed |
| T-01-04 | Denial of Service | --cov-fail-under in CI | accept | Coverage threshold can cause CI to fail; intentional gate, not a DoS vector |
</threat_model>

def chat(self, user_prompt, response_model=None, max_tokens=8192):
    base_prompt = user_prompt
    repair_suffix = (
        "\n\nIMPORTANT: Return only valid JSON that conforms to the schema in "
        "<response_format>. Do not wrap the JSON in markdown fences or add prose."
    )
    last_error: Exception | None = None
    for attempt in range(2):
        prompt = base_prompt if attempt == 0 else base_prompt + repair_suffix
        self._add_to_history("user", prompt)
        response = self.send_message(prompt, max_tokens, response_model)
        self._log_response(response)  # MUST be called — drives cost tracking
        response_text = self.get_response(response)
        if response_model is not None:
            try:
                parsed = self._validate_response(response_text, response_model)
            except Exception as exc:
                last_error = exc
                continue
            self._add_to_history("assistant", str(parsed))
            return parsed
        self._add_to_history("assistant", response_text)
        return response_text
    raise LLMError("...") from last_error

    **_run_subprocess** (shared subprocess dispatch, security-critical):
    ```python
    def _run_subprocess(self, cmd: list[str]) -> dict[str, Any]:
        """Run cmd in a sanitised env; return parsed JSON payload.

        Security: always list-form cmd, never shell=True; stdin=DEVNULL prevents
        hanging on interactive auth prompts; env vars stripped per _env_strip_keys.
        """
        env = os.environ.copy()
        for key in self._env_strip_keys:
            env.pop(key, None)

        try:
            completed = subprocess.run(
                cmd,
                capture_output=True,
                stdin=subprocess.DEVNULL,
                cwd=self._workdir,
                env=env,
                text=True,
                timeout=self._timeout_seconds,
                check=False,
            )
        except subprocess.TimeoutExpired as exc:
            raise CLITimeoutError(
                f"{self.binary_name} timed out after {self._timeout_seconds}s"
            ) from exc

        if completed.returncode != 0:
            stderr = completed.stderr.strip() or "no stderr"
            lower = stderr.lower()
            if "permission" in lower or "sandbox" in lower:
                raise CLISandboxError(
                    f"{self.binary_name} sandbox rejection: {stderr}"
                )
            if "auth" in lower or "login" in lower or "401" in stderr:
                raise CLIAuthError(
                    f"{self.binary_name} auth failure: {stderr}"
                )
            raise CLIRuntimeError(
                f"{self.binary_name} exited {completed.returncode}: {stderr}"
            )

        stdout = completed.stdout.strip()
        if not stdout:
            raise CLIParseError(f"{self.binary_name} returned empty stdout")

        try:
            return json.loads(stdout)
        except json.JSONDecodeError as exc:
            snippet = stdout[:500]
            raise CLIParseError(
                f"{self.binary_name} returned non-JSON stdout: {snippet}"
            ) from exc
    ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| config → subprocess | workdir, binary_name, and other config strings reach subprocess cmd assembly |
| subprocess stdout → JSON parser | Arbitrary bytes from the CLI binary enter the JSON parsing path |
| os.environ → subprocess env | Environment variables (including secrets) may propagate to child process |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | `_run_subprocess` cmd assembly | mitigate | `cmd` MUST be `list[str]`; `shell=True` is forbidden. Type annotation enforces this. Test `TestRunSubprocess::test_uses_list_form` verifies the call at runtime. |
| T-03-02 | Information Disclosure | `_run_subprocess` env copy | mitigate | `env = os.environ.copy()` + explicit `env.pop(key)` for each key in `_env_strip_keys`. Each provider subclass declares the keys it strips (e.g., `ANTHROPIC_API_KEY`). Base class never hardcodes key names. |
| T-03-03 | Elevation of Privilege | `binary_name` PATH resolution | accept | `probe()` will log the resolved path from `shutil.which(self.binary_name)`. Full path pinning is a Phase 10 hardening item. Risk is LOW for a developer/CI tool where PATH is operator-controlled. |
| T-03-04 | Denial of Service | subprocess stdout buffering | accept | `capture_output=True` buffers stdout in memory. Output is unbounded in theory; `max_tokens` limits prompt size but not response. Document limit; full fix (streaming or size cap) deferred to Phase 10 per RESEARCH.md. |
| T-03-05 | Denial of Service | `probe()` hanging on interactive prompts | mitigate | `stdin=subprocess.DEVNULL` is set in `_run_subprocess` AND must also be set for the `--version` probe subprocess call inside `probe()`. Test `TestProbe::test_binary_missing` covers the none-found path; pitfall documented in RESEARCH.md Pitfall 5. |
</threat_model>

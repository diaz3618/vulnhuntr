# Plan 09-01: Add InvariantViolationError and Production Guards

## Goal

Add the `InvariantViolationError` exception class to `vulnhuntr/core/trace.py`, export
it from `vulnhuntr/core/__init__.py`, and add two guard raises in production code
(`FallbackLLM.chat()` and `ClaudeCodeLLM.send_message()`) that fire loudly when
internal state constraints are broken at runtime.

**Step A — vulnhuntr/core/trace.py**

Append the following class definition at the end of the file (after `ExecutionTracer`):

```python
class InvariantViolationError(RuntimeError):
    """Raised when an internal state invariant is broken at runtime.

    This is a programming error, not a recoverable LLM-level failure.
    Prefer this over bare RuntimeError for debuggability — callers can
    inspect `.invariant` and `.actual_value` without parsing the message.

    Args:
        message: Human-readable description of the violation.
        invariant: Machine-readable key identifying which invariant fired
                   (e.g. "active_in_registry", "session_mode_is_known").
        actual_value: The observed value that triggered the violation, or None.
    """

    def __init__(self, message: str, *, invariant: str, actual_value: Any = None) -> None:
        super().__init__(message)
        self.invariant = invariant
        self.actual_value = actual_value
```

No new imports are needed — `Any` is already imported in `trace.py` from `typing`.

**Step B — Add guard in send_message()**

Locate the line in `ClaudeCodeLLM.send_message()`:
```python
        session_mode = self._policy.session_mode if self._policy else "stateless"
```
Immediately after that line, insert:
```python
        _VALID_SESSION_MODES = frozenset({"stateless", "continue", "resume"})
        if session_mode not in _VALID_SESSION_MODES:
            raise InvariantViolationError(
                f"Unrecognized session_mode: {session_mode!r}",
                invariant="session_mode_is_known",
                actual_value=session_mode,
            )
```

`_VALID_SESSION_MODES` is defined inline as a local variable (not module-level) so it lives adjacent to where it is consumed. This is the simplest placement with no side-effects on other code paths.

The result reads:
```python
        session_mode = self._policy.session_mode if self._policy else "stateless"
        _VALID_SESSION_MODES = frozenset({"stateless", "continue", "resume"})
        if session_mode not in _VALID_SESSION_MODES:
            raise InvariantViolationError(
                f"Unrecognized session_mode: {session_mode!r}",

                actual_value=session_mode,
```
